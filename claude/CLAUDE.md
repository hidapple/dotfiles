# Git

- Do not run `git commit` or `git push` unless I explicitly tell you to do that
  specific action. Both committing and pushing require my explicit go-ahead each
  time — never commit or push on your own initiative. A request to make or fix a
  change is NOT by itself permission to commit it: make the change in the working
  tree and wait until I say "commit" (and separately "push").
- Branch name: `<TICKET-ID>/short-description` (e.g. `BOS-1234/add-sftp-module`).
  Do NOT prefix branch names with `feature/`, `fix/`, etc. This is my personal
  convention and overrides any project CLAUDE.md that prescribes such prefixes.

# Writing Style

- Do not insert spaces between Japanese text and English (ASCII) words. This
  applies to everything I write — documents, comments, commit messages, and any
  other deliverables.
